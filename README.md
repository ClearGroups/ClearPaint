# ClearPaint
A simple (local) graphics editor without tracking and telemetry. Support for Russian and English languages. Please read it carefully before use. README.md

# RU:

# Возможности
- Собственное расширение .clep
- Сохранение настроек каждого документа с помощью конфигурации. Конфиг появляется в папке ClearConfig в подпапке ClearPaint, его удалять нельзя!
- Переключение языков
- Изменение цветов пера и фона
- Отображение несохранённых изменений
- Простой интерфейс

# Установка

Скачай ClearPaint.exe из [Releases] (https://github.com/ClearGroups/ClearPaint/releases) и запусти.

# EN:

# Features
- Own extension .clep
- Saving the settings of each document using configuration. The config appears in the ClearConfig folder in the ClearPaint subfolder, it cannot be deleted!
- Language switching
- Change pen and background colors
- Display of unsaved changes
- Simple interface
# Installation

Download it ClearPaint.exe from [Releases] (https://github.com/ClearGroups/ClearPaint/releases ) and launch it.
